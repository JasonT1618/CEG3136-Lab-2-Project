# CEG3136-Lab-2-Project
This project is for the uOttawa CEG3136 Computer Architecture II lab project, as of lab 2. The project features an Alarm and Calculator application, which the user can switch between. The project is designed to run from the STM32CubeIDE for a specialized circuit board using the STM32L552ZE MCU, powered by an ARM Cortex M33 32-bit processor. 

## Overview
The implementations of all application source files, excluding main.c, was programmed by Jason Tong and Ken Shan; These are the source files alarm.c, calc.c, and maths.s, found under CEG3136_Lab2/Src. The driver files, located under CEG3136_Lab2/Drivers/Inc and CEG3136_Lab2/Drivers/Src, are mostly provided for the lab, with the exception of the definitions of certain functions in gpio.c being programmed by us; those functions being GPIO_Enable(), GPIO_PortEnable(), GPIO_Mode(), GPIO_Config(), GPIO_AltFunc(), GPIO_Input(), GPIO_Output(), and GPIO_Toggle().

**The Alarm app** implements a motion-sensing alarm with 3 states, DISARMED, ARMED, and TRIGGERED. In DISARMED, the alarm does not respond to motion and has all LEDs off. The ARMED state toggles a blue and a green LED in alternation and can trigger the system when motion is sensed. The TRIGGERED state turns on only the red LED and activates a buzzer incorporating various frequencies of sound. DISARMED can transition into ARMED on release of a button from a short press. From ARMED, the state can transition back to DISARMED from holding the button or into TRIGGERED when motion is detected. From TRIGGERED, the state can transition to ARMED from a short button press, or into DISARMED from holding the button.

**The Calculator app** uses a set of touch pads, with numeric pads ranging from 0 to 9, a pad for SHIFT that acts as the backspace key, and a pad for NEXT that acts as the enter key. The user input to the calculator is taken from the touchpad and the results are displayed on the LCD module. The operations supported are Add, Subtract, Multiply, Divide, find greatest common denominator (GCD), Factorial, find nth place of Fibonacci sequence, Sort in ascending order, and Average. The touchpad also doubles as the way for users to navigate the interface.

The user can switch between the Alarm and Calculator app using a button on the circuit board, which triggers a hardware interrupt that increments the variable 'Page_t openPage' in display.c; the exact implementation of the logic can be found in CEG3136_Lab2/Drivers/Src/display.c. The openPage variable is used to decide what to display on the LCD module and is also used to hide user inputs from being interpreted by inactive apps.
